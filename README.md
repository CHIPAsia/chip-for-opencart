# CHIP for OpenCart

This module adds CHIP payment method option to your OpenCart.

## Installation

The installation files differs by OpenCart version. Choose your OpenCart version:

* [OpenCart 1.5.x](https://github.com/CHIPAsia/chip-for-opencart/releases/latest/download/chip-opencart-1.5.zip)
* [OpenCart 2.0.x & 2.1.x](https://github.com/CHIPAsia/chip-for-opencart/releases/latest/download/chip-opencart-2.0.zip)
* [OpenCart 2.2.x](https://github.com/CHIPAsia/chip-for-opencart/releases/latest/download/chip-opencart-2.2.zip)
* [OpenCart 2.3.x](https://github.com/CHIPAsia/chip-for-opencart/releases/latest/download/chip-opencart-2.3.zip)
* [OpenCart 3.0.x](https://github.com/CHIPAsia/chip-for-opencart/releases/latest/download/chip-opencart-3.0.zip)
* [OpenCart 4.0.0](https://github.com/CHIPAsia/chip-for-opencart/releases/latest/download/chip-opencart-4.0.zip)
* [OpenCart 4.1.x](https://github.com/CHIPAsia/chip-for-opencart-4.1)

## Configuration

Set the **Brand ID** and **Secret Key** in the plugins settings.
